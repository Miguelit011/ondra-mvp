# 🎵 Ondra - MVP Arquitectura de Microservicios

Proyecto académico desarrollado para la asignatura **ASEE (Arquitecturas Software para Entornos Empresariales)**  
Universidad de Extremadura - Grupo GC03

## 🧩 Estructura del sistema
- **Frontend Angular** → `/frontend/ondra-angular`
- **Microservicio Usuarios** → `/backend/usuarios-service`
- **Microservicio Contenidos** → `/backend/contenidos-service`
- **Microservicio Recomendaciones** → `/backend/recomendaciones-service`

## 🧰 Stack tecnológico
- **Backend:** Spring Boot 3 + Java 17 + PostgreSQL
- **Frontend:** Angular + Tailwind CSS
- **Infraestructura:** GitHub + pgAdmin local
- **Servicios externos:** Cloudinary, Firebase Auth (Google)

## 🧭 Organización de ramas
- `main` → versión estable
- `develop` → integración
- `feature/...` → desarrollo por módulo

## 🚀 Cómo ejecutar
1. Configura PostgreSQL local.
2. Arranca cada microservicio (Spring Boot).
3. Inicia el frontend Angular con `npm start`.
